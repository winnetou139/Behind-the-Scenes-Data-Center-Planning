## Yang Didukung
- Vault adalah sebuah folder di file system lokal
- Note disimpan sebagai file Markdown berformat plain text
- Folder .obsidian di root vault menyimpan pengaturan vault
- Obsidian otomatis me-refresh saat file diubah dari luar aplikasi
- Pengaturan global di Windows berada di %APPDATA%\Obsidian
